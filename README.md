## Install on PowKiddy V90

Download the [latest SimpleMenu v4.1 release](https://github.com/taichikuji/simplemenu/releases/tag/v4.1) and extract its ZIP file.

1. Connect your PowKiddy V90 to your computer with USB-C, turn it on, and run **USB-MTD** to expose its storage.
2. Copy the extracted `simplemenu` folder into `apps/simplemenu` on the main partition (`/mnt/apps/simplemenu` on the device).
3. Open **Explorer** on the V90, navigate to `apps/simplemenu`, and run `deploy.sh`.

**MiyooCFW 1.3.3 users:** use [SimpleMenu v3.0](https://github.com/taichikuji/simplemenu/releases/tag/v3.0) instead. See the [v4.1 release notes](https://github.com/taichikuji/simplemenu/releases/tag/v4.1) for the complete installation instructions.
